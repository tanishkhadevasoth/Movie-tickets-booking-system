# Movie Ticket Booking System

## Project Description

The Movie Ticket Booking System is a simple web-based application developed using HTML, CSS, and JavaScript. The project is designed to automate the movie ticket reservation process by allowing users to enter customer details, select movies, choose show timings, specify the number of tickets, and generate booking confirmations instantly.

This project helps reduce manual ticket booking efforts and demonstrates the implementation of basic cinema management functionalities through a user-friendly interface.

---

# Features

- Movie Selection
- Show Time Selection
- Ticket Reservation
- Customer Details Management
- Automatic Ticket Cost Calculation
- Booking Confirmation Generation
- Simple and Responsive User Interface

# How to Run the Project

1. Download or clone the repository

```bash
git clone https://github.com/your-username/MovieTicketBookingSystem.git
```

2. Open the project folder in VS Code

3. Open `index.html`

4. Run using:
- Live Server Extension
OR
- Double-click `index.html`

5. The project will open in your browser
